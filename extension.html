Themes, scenes, and a Chrome extension for live output.

Extension

A Chrome add-on that restyles Vixi output pages with mosaic themes, message themes, and optional animated backgrounds.

Install

Chrome will not install from the download click. Unzip extension.zip, then:

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Click Load unpacked
  4. Select the unzipped extension folder

On first install, Chrome opens a Finish setup tab. Complete that before importing theme engines.

Finish setup (required for imported engines)

Built-in mosaic and message themes work right away. Packs you import with a *-engine.js file need one extra Chrome setting, or they mount as a black screen on Vixi.

  1. Open chrome://extensions → Dynamic Backgrounds → Details (the popup and setup tab also have an Open extension details button).
  2. Turn on Allow User Scripts (Chrome 138+). On older Chrome, keep Developer mode on at chrome://extensions instead.
  3. Click Reload on the extension card if you just toggled the setting.
  4. In the popup (or the setup tab), confirm the status is green, then hard-refresh the Vixi output tab.

If User Scripts is still off, the popup shows a red Finish setup banner at the top until it is fixed.

After you change files in the folder, click Reload on the extension card. To rebuild the zip from the repo:

rm -f extension.zip && zip -r extension.zip extension -x "*.DS_Store"

Replace Vixi themes

The popup header is the kill switch. Off leaves every page alone. On applies the rest of the popup — mosaic and message themes, stage, chrome, and optional iframe rules — to matching output URLs.

Mosaic vs message

Pick one mosaic theme and one message theme. Mosaic restyles the live photo grid. Message restyles a single capture with its caption and name. Off in either dropdown keeps Vixi’s own layout for that kind.

Some mosaic themes (Polaroid wall, Live mosaic, 3D flip wall, Cube field, Depth Field, Pedestals, and imported packs that declare size/color) show size and color controls under the dropdown. Message themes show color and, when declared, motion. Defaults match the original look (size 100%).

Browse the looks on the Themes page. Those tiles are a catalog, not a picker — you still choose the theme in the popup.

Names ending in * are brand-aware mosaics: when Show QR / Show logo are on, they reflow to leave room for chrome; with both off they use the full stage. Mosaic feed changes update the photo pool; on-screen cards change through each theme’s own transitions rather than flashing everything at once.

Message themes stay black until the first capture paints, so a cold load does not flash QR/logo alone. Mosaic ↔ message handoffs crossfade under cover. Back-to-back messages stay on the theme; a CTA, stream, live camera, video, or URL playlist item is left as Vixi painted it. When mosaic returns after that, the theme remounts so Polaroid and the other walls play their enter motion instead of unparking the old cards.

Stage aspect

Stage defaults to Match Vixi, which uses the canvas ratio Vixi is already showing. Match the window fills the browser and tracks its size. Presets cover 16:9, 9:16, 4:3, 1:1, 21:9, and more — those letterbox the leftover window in black. Choose Custom to type any width:height.

Themes restack for portrait. Mosaic cards stay 2:3 — they do not flip to a 3:2 crop.

Background media

In the popup Background section you can use a link/iframe, a one-off upload, or a Backgrounds folder on disk (pick once, then Rescan when you add files — no extension reload). Chrome remembers the folder; each time you open the popup, click Allow access once so it can list files again (browser security).

Size limits: about 64 MB per file from the backgrounds folder; about 3.5 MB for one-off uploads (stills are compressed).

Supported formats:

  • Images: JPEG, PNG, WebP, BMP, AVIF, SVG
  • GIF (animated)
  • Video: MP4, WebM, MOV, M4V, Ogg/OGV

Prefer H.264 MP4 or WebM for video. HEIC from iPhone is not supported — convert to JPEG or PNG first. Fit modes are Fill, Fit, Stretch, and Center.

Background, QR, and logo

Mosaic and message each have their own three checkboxes: Show background, Show QR code, Show logo. While a theme is on, Vixi’s background, QR, and logo stay hidden unless that kind’s toggles are on. Mosaic chrome never clones onto a message theme, and the other way around.

When the background is shown, it fills the current stage. The theme places QR and logo — default chrome is logo top-left and QR bottom-right if the theme does not set data-qr / data-logo.

Custom themes can pin exact placement with those attributes and use CSS classes dyn-show-qr / dyn-show-logo / dyn-show-bg for four layout variants (neither, logo only, QR only, both). See themes/SPEC.md.

Any output URL vs specific rows

Specific output URLs win. Paste an output URL and an iframe (or background URL) on a row. A match always applies that iframe, even if Any output URL is blank.

Any output URL is the fallback for recognized output pages that do not match a row. Leave it blank to skip unmatched pages.

Tokens and extra query params on an output URL are ignored when matching.

Imported themes

The popup Imported themes section uses Import packs…. Select several .json files, optional engines, and optional font files (.woff2 / .woff / .ttf / .otf) at once. Matching is by engine / filename and by each JSON fontFile / fontFaces entry. A pack can use several custom fonts plus Google Fonts. Shared fonts are stored once; re-importing the same ids replaces. Sample packs and the import walkthrough are on Create.

Engine packs only run after Allow User Scripts is on (see Finish setup above). JSON-only packs do not need that setting.

Reload the unpacked extension after you update files.
