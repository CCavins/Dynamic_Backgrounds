Extension

A Chrome add-on that restyles Vixi output pages with mosaic themes, message themes, and optional animated backgrounds.

Install

Chrome will not install from the download click. Unzip extension.zip, then:

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Click Load unpacked
  4. Select the unzipped extension folder

After you change files in the folder, click Reload on the extension card. To rebuild the zip from the repo:

rm -f extension.zip && zip -r extension.zip extension -x "*.DS_Store"

Master on / off

The popup switch is the kill switch. Off leaves every page alone. On applies the rest of the popup — themes, stage, chrome, and iframe rules — to matching output URLs.

Mosaic vs message

Pick one mosaic theme and one message theme. Mosaic restyles the live photo grid. Message restyles a single capture with its caption and name. Off in either dropdown keeps Vixi’s own layout for that kind.

Browse the looks on the Themes page. Those tiles are a catalog, not a picker — you still choose the theme in the popup.

Stage aspect

Stage resizes Vixi’s real output canvas to a ratio, then letterboxes the leftover window in black. Presets cover 16:9, 9:16, 4:3, 1:1, 21:9, and more. Choose Custom to type any width:height. Auto still follows the window.

Themes restack for portrait. Mosaic cards stay 2:3 — they do not flip to a 3:2 crop.

Background, QR, and logo

Mosaic and message each have their own three checkboxes: Show background, Show QR code, Show logo. While a theme is on, Vixi’s background, QR, and logo stay hidden unless that kind’s toggles are on. Mosaic chrome never clones onto a message theme, and the other way around.

When the background is shown, it fills the current stage. The theme places QR and logo — default chrome is logo top-left and QR bottom-right if the theme does not set data-qr / data-logo.

Any output URL vs specific rows

Specific output URLs win. Paste an output URL and an iframe (or background URL) on a row. A match always applies that iframe, even if Any output URL is blank.

Any output URL is the fallback for recognized output pages that do not match a row. Leave it blank to skip unmatched pages.

Tokens and extra query params on an output URL are ignored when matching.
