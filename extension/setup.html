Finish setup

One Chrome setting is required before imported theme engines (JSON + .js) can run on Vixi. Without it, those themes show a black screen.

Checking…

  1. Click Open extension details below.
  2. Find Allow User Scripts and turn it On.
    Older Chrome: on chrome://extensions, turn on Developer mode instead.
  3. Return here and click Recheck. This page should turn green.
  4. Open a Vixi output tab and hard-refresh it (Cmd+Shift+R / Ctrl+Shift+R).

Built-in themes work without this. You only need Allow User Scripts for packs you import with an engine file.
