Replace Vixi themes

On restyles matching output with the themes below. Off leaves Vixi as-is.

Stage

Match Vixi uses the canvas ratio Vixi is already showing. Match the window fills the browser and tracks its size. Other ratios grow until they hit an edge, then letterbox in black.

Mosaic theme

Uses the live mosaic photos and restyles the grid. Off keeps Vixi’s layout.

* Themes marked with an asterisk leave a rail for the QR code and logo when those toggles are on, and use the full stage when they are off.

Mosaic-only. Uses the mosaic item’s background, QR, and logo — not the message ones. Hidden unless turned on. The background fills the stage; * themes shift the mosaic to leave room for QR and logo.

Message theme

Uses the live capture photo and caption. Off keeps Vixi’s layout.

Message-only. Uses the capture item’s background, QR, and logo — not the mosaic ones. Hidden unless turned on. The background fills the stage; the theme places QR and logo.

Background

Used on output pages that do not match a specific row below. Link/iframe, one-off upload, or a local backgrounds folder. When a message or mosaic theme is on, turn on Show background for that theme to keep this behind it.

Backgrounds folder No folder

Pick a folder once (outside the extension). Add files in Finder, then Rescan — no extension reload. Size limit: about 64 MB per file from the folder. After Chrome restarts you may need Allow access once.

Formats: JPEG, PNG, WebP, GIF, BMP, AVIF, SVG · MP4, WebM, MOV, M4V, Ogg/OGV.

Active media No file

One-off upload max about 3.5 MB (stills are compressed). Prefer the folder above for larger video/GIF files (up to ~64 MB).

Specific output URLs

A matching output URL always wins, even if Any output URL is blank.

Imported themes

  1. Select theme .json files, optional *-engine.js files, and optional font files (.woff2 / .woff / .ttf / .otf) from your themes folder.
  2. Matching is automatic: engines by engine / filename; fonts by each JSON fontFile / fontFaces[].fontFile basename. Shared fonts are stored once. A pack can use several custom fonts plus Google Fonts.
  3. Same theme id (or same font / engine id) replaces the previous import.
