Mosaic theme

Uses the live mosaic photos and restyles the grid. Off keeps Vixi’s layout.

* Themes marked with an asterisk leave a rail for the QR code and logo when those toggles are on, and use the full stage when they are off.

Mosaic-only. Uses the mosaic item’s background, QR, and logo — not the message ones. Hidden unless turned on. The background fills the stage; * themes shift the mosaic to leave room for QR and logo.

Message theme

Uses the live capture photo and caption. Off keeps Vixi’s layout.

Message-only. Uses the capture item’s background, QR, and logo — not the mosaic ones. Hidden unless turned on. The background fills the stage; the theme places QR and logo.

Imported themes

  1. Select one or many theme .json files (and their *-engine.js files if needed).
  2. Matching is automatic by engine / filename (e.g. mosaic-xmas-tree.json ↔ mosaic-xmas-tree-engine.js).
  3. Standalone JSON packs import without an engine. Same id replaces.
